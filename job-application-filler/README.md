# Job Application Filler (Autopilot-X)

This folder contains the complete, battle-tested system prompt and guidelines for configuring an autonomous agent to execute high-velocity, high-precision job applications across modern ATS portals (AshbyHQ, Greenhouse, Lever, Workable, etc.).

## Contents

- `AUTOPILOT_X_GLOBAL_TEMPLATE.md`: The universal system prompt template parameterized with `{{ PLACEHOLDER }}` tokens across all 10 core operational sections:
  1. Candidate Identity Vault
  2. Resume & Asset Paths
  3. Flagship Projects (Live-verified routing)
  4. Skills & Certifications
  5. Job Tracker Configuration (Notion & Google Sheets)
  6. Role Scope & Strict Exclusions
  7. Application Execution Rules (Zero-blanks policy, direct ATS focus)
  8. "Pause & Go" Communication Protocol
  9. Daily Execution Standards (10+ submissions/day quota)
  10. Context-Adaptive Cover Letter Framework

## How to Use

1. Copy `AUTOPILOT_X_GLOBAL_TEMPLATE.md`.
2. Replace all `{{ PLACEHOLDER }}` variables with your canonical personal, project, and tracker data.
3. Supply the file as the system prompt or agent skill for your autonomous AI assistant.
